The rich-text editor for Angular. Free, all of it.

Tables, images, task lists, Markdown shortcuts, safe HTML in and out, light and dark themes — in one MIT-licensed package built on ProseMirror. No premium tier, no cloud key, no icon font, no CSS framework.

Everything a document needs

The features other editors sell as add-ons ship in the box.

Text formatting

Bold, italic, underline, strike, sub/superscript, inline code, font family and size, text colour and highlight.

Structure

Headings H1–H6, quotes, code blocks, horizontal rules, alignment and indentation.

Lists

Bulleted, numbered and task lists with real checkboxes; nest with Tab and Shift+Tab.

Tables

Insert any size, add and delete rows and columns, merge and split cells, header rows and columns, drag to resize columns.

Images

From a URL, an upload, paste or drag-and-drop. Resize with a handle, float left or right, centre, add alt text. Plug in your own upload endpoint.

Markdown shortcuts

Type #, -, 1., > or ``` at the start of a line; Backspace undoes it.

Safe HTML

The schema is the allowlist: scripts, event handlers, javascript: links and SVG images never get through. Use the sanitizer on its own, too.

Angular forms

A ControlValueAccessor: formControlName, [formControl], ngModel, disabled, touched and required behave like a native input.

Theming

Every colour is a CSS variable; light and dark themes follow the system or your data-theme. Icons are inline SVG you can replace.

Localization

Every label is a locale key. English and Turkish are included; pass your own object for any other language.

Placeholder & counts

Placeholder text for empty documents, word and character counts as an output.

Find & replace

Ctrl+F opens a find bar with match count, match case, whole words, replace and replace all.

Video

Paste a YouTube or Vimeo link to embed the player; other iframes are never let in.

Autolink

Typed and pasted URLs turn into links; paste a URL over selected text to link it.

Undo & keyboard

Full history, familiar shortcuts (Ctrl+B, Ctrl+Z…), Tab through table cells.

Get started

The npm release is being prepared. Until then, build the package from the repository.

  1. Install (once released): 
    npm install we-editor-angular
  2. Add the theme to your global styles (angular.json → styles): 
    "node_modules/we-editor-angular/styles/we-editor-theme.scss"
  3. Use it like any form control: 
    import { WeEditorComponent } from 'we-editor-angular';

@Component({
  standalone: true,
  imports: [WeEditorComponent, ReactiveFormsModule],
  template: `<we-editor [formControl]="body" placeholder="Write something…" />`
})
export class PostFormComponent {
  body = new FormControl('<p>Hello</p>', { nonNullable: true });
}
